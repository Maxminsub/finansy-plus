# Финансы+ — личный финансовый помощник для iPhone

Это адаптивный сайт-приложение (PWA): доходы, расходы, цели и простая аналитика. Данные сохраняются локально в браузере на устройстве.

## Что работает
- Добавление доходов и расходов, категории, даты и фильтры
- Баланс и сводка за текущий месяц
- Финансовые цели и ручное пополнение целей
- Аналитика по месяцам и категориям расходов
- Выбор валюты, настройка планируемой зарплаты
- Экспорт резервной копии в JSON
- PWA-манифест, иконка и кэш для базовой офлайн-работы

## Как установить на iPhone как приложение
1. Разместите содержимое этой папки на HTTPS-хостинге. Например, GitHub Pages, Netlify или любой свой хостинг с HTTPS.
2. Откройте адрес сайта именно в Safari на iPhone.
3. Нажмите «Поделиться» (квадрат со стрелкой вверх).
4. Выберите «На экран Домой».
5. Включите «Открывать как веб-приложение», если этот переключатель показывается, и нажмите «Добавить».
6. Запустите значок «Финансы+» с домашнего экрана.

Важно: открыть локальный HTML-файл недостаточно для полноценной установки PWA. Для service worker нужен HTTPS (или localhost для разработки).

## Запуск для проверки на компьютере
Если установлен Python, в папке проекта запустите:
`python3 -m http.server 8000`
Затем откройте `http://localhost:8000`.

## Приватность и ограничения
- Данные хранятся в localStorage браузера и не отправляются на сервер приложением.
- Очистка данных Safari, приватный режим или переход на другой браузер/устройство могут привести к потере записей. Регулярно экспортируйте резервную копию.
- Это личный блокнот, не банковская интеграция и не профессиональная финансовая рекомендация.
- Зарплата — плановая заметка для ориентира; её можно записывать отдельной операцией как доход.


Оформление: в настройках можно переключаться между белой и тёмной темой. Выбор сохраняется на этом устройстве.
